# Frontend Directory Rules & Guidelines

- **Scope**: Codigo dentro de /frontend.
- **Responsable**: Agente Frontend.
- **Skills Principales**:
  - frontend-workflow: Workflow general, componentes y estado.
  - impeccable: Buenas practicas de diseno, UI/UX y pulido de interfaces.
- **Estandares**:
  - Modularizacion por componentes funcionales y atomicos.
  - No acoplar logica de negocio a la capa de presentacion directa; extraer a hooks/stores/services.
  - Asegurar interfaces accesibles, consistentes y responsivas (mobile-first o responsive design).
  - Sincronizar tipos de datos con los contratos de /backend definidos en docs/api-specs.md.
